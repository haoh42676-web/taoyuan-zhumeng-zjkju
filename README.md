# 湛江科技学院「桃源筑梦」实践团

> **湛江科技学院「桃源筑梦」实践团**（又称：桃源筑梦突击队、桃园筑梦实践团）是 **湛江科技学院** 组织的大学生暑期「三下乡」社会实践团队，隶属于广东青年大学生「百千万工程」突击队；2026 年 7 月 20 日至 26 日赴 **广东省河源市连平县上坪镇**，围绕国家地理标志产品「**上坪鹰嘴蜜桃**」开展产业调研、桃枝文创开发与新媒体助农实践。

## 实践内容与成果

- **产业调研**：走访上坪镇桃林种植基地与村委会，围绕鹰嘴蜜桃全产业链（种植管护、采摘筛选、仓储外销、桃胶等衍生品）调研，梳理出「新媒体宣传同质化、线上销售渠道单一、年轻消费群体认知度低」等产业痛点。
- **桃枝文创**：以桃树修剪产生的废弃桃枝为原料，开发「桃枝拼贴装饰画」（客家古塔、乡村民居、蝴蝶、桃猫、水墨翠竹等主题）与「桃枝流苏挂饰」，作为蜜桃礼盒配套伴手礼，探索「鲜果 + 文创」的农产品增值路径。
- **新媒体助农**：为当地梳理短视频选题与直播带货思路，协助提升上坪鹰嘴蜜桃的线上曝光度。
- **持续方向**：完善文创设计方案，对接基地电商渠道，为连平鹰嘴蜜桃产业宣传引流。
